# Источники и качество данных

## Рецепты и пищевая ценность

Текущий стартовый каталог внесён вручную исключительно как демонстрационная структура для реализации вычислений. Эти значения не проверены по упаковкам или внешней базе и не подтверждены диетологом; названия/значения/состояния продуктов могут быть неполными. Интерфейс маркирует их демонстрационными и предупреждает об аллергенах. Не использовать для клинических рекомендаций.

Пока нет проверенных внешних пищевых данных и ссылок на лицензии/условия использования. До появления таких источников каждая запись должна иметь источник, дату, сырой/сухой/готовый статус и проверку единиц/аллергенов. Не дополнять отсутствующие значения случайными числами.

## Цены

Цены и упаковки в каталоге сейчас отсутствуют. Все суммы стоимости корзины скрыты; вычислительный модуль цен сам по себе не делает входные цены истинными/актуальными. Дата проверки и статус должны быть подтверждены для каждого товарного SKU и магазина/региона. Live-данные, API, ассортимент и наличие «Пятёрочки» не подключались и не исследовались как официальная интеграция.

## Изменение источников

Добавлять новые записи можно только с происхождением данных, допустимыми условиями использования, датой получения, статусом проверки, единицами/фасовкой и отметкой неопределённости. Перед массовым импортом проверить права на данные и юридические ограничения.
