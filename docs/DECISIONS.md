# Принятые решения

## 2026-10-19

1. **Начать с локального React + TypeScript + Vite MVP.** В исходной папке не оказалось приложения; выбран рекомендованный современный стек без платной инфраструктуры. Tailwind не добавлен: компактная CSS-система позволяет не раздувать зависимости и объём настройки.
2. **Не подключать авторизацию, БД или внешний AI в первом этапе.** Без продукта/аккаунта и согласования обработки персональных данных безопаснее локальное хранение; UI не изображает серверную регистрацию или синхронизацию.
3. **Воспроизводимость и честная маркировка важнее привлекательности цен.** Демонстрационные ручные макросы помечены как непроверенные. Цены отсутствуют, поэтому интерфейс не отображает сумму; формула упаковок проверяется отдельными тестами.
4. **Взрослая формула применяется только с 18 лет.** В профиле/валидации явно ограничен диапазон; детский режим и индивидуальные медицинские цели не предлагаются.
5. **План детерминированный и без случайных замен.** Аллергии и ограничения фильтруются до подбора; если подходящего рецепта или альтернативы нет, действие объясняет проблему.
6. **Изменение рецепта пересчитывает только зависимые результаты.** Идентификаторы остальных приёмов сохраняются; список покупок формируется заново из текущего плана.
7. **Денежная модель — целые копейки и целые упаковки.** Цены пока не являются данными каталога; отсутствие цен явно показано.
8. **Публичный запуск отложен.** Российские требования к обработке персональных данных, локализации, источникам и юридическим текстам требуют отдельной проверки.
9. **PWA сделана через лёгкий Vite-плагин без тяжёлого PWA-пакета.** Версионированный worker кэширует только оболочку и хешированные статические assets; пользовательские данные остаются в `localStorage`, не помещаются в Cache Storage. Новый SW сообщает об обновлении и активируется по явному нажатию.
10. **Установка различается по платформам.** Chromium показывает настоящий `beforeinstallprompt`, когда браузер считает приложение устанавливаемым; iOS предлагает Safari-инструкцию, а не неподдерживаемый программный диалог. Публичное HTTPS-развёртывание не выполнялось.
