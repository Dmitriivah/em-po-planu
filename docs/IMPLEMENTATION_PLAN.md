# План реализации и критерии этапов

Полный перечень обязанностей — [AGENTS.md](../AGENTS.md). Этапы не закрываются только наличием экранов: нужны измеримые проверки из [TESTING.md](./TESTING.md).

| Этап | Результат | Критерий завершения |
|---|---|---|
| 0. Аудит и проектирование | Инвентаризация, спецификация, архитектурные решения, план | Исходные файлы/ограничения проверены, незавершённое записано |
| 1. Основа приложения | Навигация, адаптивный интерфейс, состояния | Страницы/действия доступны с клавиатуры и мобильного экрана |
| 2. Питание | Валидация профиля, BMR/TDEE, цели и КБЖУ | Формулы, активности, цели и ошибки покрыты тестами |
| 3. Рецепты | Структурированные ингредиенты и источники | Расчёт порций и явное качество данных проверены |
| 4. Меню | Детерминированный подбор, итоги и замены | Фильтры не нарушают аллергены, замена сохраняет другие блюда |
| 5. Семья | 1–12 участников, личные цели и общие блюда | Индивидуальные порции/ограничения и общий расход протестированы; детский режим безопасен |
| 6. Покупки/бюджет | Запасы, единицы, упаковки, 2 стоимости, покупки | Эталон 200 г / 500 г / 150 ₽ даёт 60 ₽ использовано и 150 ₽ покупка; нет цены — нет выдуманной суммы |
| 7. Хранение/безопасность | Авторизация, миграции, доступ и восстановление | Серверные права протестированы; секреты не раскрыты |
| 8. Каталог/цены | Контролируемый импорт, статусы, история, администрирование | Дубликаты/ошибки/дата/источник проверяются; нет ложной интеграции |
| 9. Полная проверка | Сценарии, регрессия, документация запуска | Сборка, тесты, мобильный UX и известные ограничения зафиксированы |

## Очерёдность и зависимости

Сначала закончить персональный сценарий на локальном каталоге (профиль → меню → рецепт → список), включая тесты. Затем семейные порции, pantry и расчёт по упаковкам; после утверждения модели данных подключать backend/auth/RLS. Цены и магазин — только на документированных разрешённых данных. AI и платежи не нужны для базового запуска.

## Условия остановки/согласования

Не совершать платные, публичные, необратимые действия. Запросить согласие до расходов, публикации, передачи/миграции пользовательских данных, провайдера с возможной зарубежной локализацией или юридически значимой интеграции.
