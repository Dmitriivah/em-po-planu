# Ем по плану

Русскоязычный прототип планирования питания. Первая версия работает локально: пользователь сохраняет профиль, формирует детерминированное меню из структурированных рецептов, открывает рецепт с расчётом КБЖУ и получает объединённый список ингредиентов.

## Запуск

Требуется Node.js 20.19+ или 22.12+ и npm.

```powershell
npm.cmd install
npm.cmd run dev
```

Для проверки и production-сборки:

```powershell
npm.cmd test
npm.cmd run build
```

В этой среде PowerShell блокирует `npm.ps1`, поэтому используйте `npm.cmd`.

## Установка как приложение (PWA)

Для production-сборки сгенерируйте иконки и соберите приложение:

```powershell
npm.cmd run icons
npm.cmd run build
npm.cmd run preview -- --host 0.0.0.0
```

Откройте адрес предпросмотра на телефоне по HTTPS. Service worker включён только в production-сборке и работает только через HTTPS или на `localhost`; предпросмотр на сетевом IP без HTTPS не обеспечивает установку. В Android Chrome используйте системную кнопку установки, если браузер предлагает её. На iPhone/iPad откройте страницу в Safari → «Поделиться» → «На экран Домой» → «Добавить». Возможность установки зависит от браузера и версии ОС.

Уже загруженная оболочка и встроенные статические ресурсы могут открываться при временном отсутствии сети. Профиль и план читаются из локального хранилища этого браузера; первый визит без сети, синхронизация между устройствами и загрузка внешних данных офлайн не поддерживаются. Обновление сервис-воркера сообщает о новой версии и применяется по нажатию «Обновить». Установка не требует аккаунта или платного сервиса.

Исходные PNG-иконки можно воспроизвести командой `npm.cmd run icons`; файлы попадают в `public/icons/`.

На iPhone/iPad установка предусмотрена через Safari. Chrome для iOS может не показывать ту же команду «На экран Домой»; при необходимости откройте сайт в Safari. Service worker и автоматический диалог установки зависят от браузера и защищённого контекста.

`.env.example` сейчас пуст по смыслу: серверные сервисы и ключи не нужны. Данные профиля, план и отметки покупок хранятся в `localStorage` текущего браузера; между устройствами они не синхронизируются.

## Точность и ограничения

Рецептурный каталог в этой версии — явно обозначенные демонстрационные записи. Пищевые значения внесены вручную, не сверены с упаковками и не являются проверенным источником. Поэтому меню и КБЖУ приблизительны. Каталог цен не подключён: приложение намеренно не показывает вымышленные цены или стоимость корзины. Интеграции с «Пятёрочкой», регистрация на сервере, семейные профили и медицинские рекомендации отсутствуют.

Перед публичным запуском необходимы проверка источников данных, юридическая проверка требований к персональным данным и условий использования источников, а также полноценное серверное хранение и разграничение доступа.
